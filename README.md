# Welcome to the old clone of aetlis.io, the worst of the worst!

The project fell into the hands of certain groups and spawned even worse versions under different names, so I felt like I had to share the original.

You get the worst physics engine you could ever ask for, with terrible optimization on top, all in one package!

It's mainly inspired by Luka's [MultiOgar-Edited](https://github.com/Luka967/MultiOgar-Edited). I made it back when I was terrible at making ball games and my whole workflow was telling an AI "hey, do this and that, but I'm never gonna check it". But hey, no worries, here it is!
